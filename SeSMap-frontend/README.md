# SeSMap Frontend

Vue 3 + Vite frontend for SeSMap: the semantic subspace map, Semantic Source Gallery, Chat with LLM, and Stepwise Analysis View.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
```

Start the backend first (`python3 app.py`); Vite proxies `/api/*` to `http://127.0.0.1:5000`.

```bash
npm run build      # production build → dist/
```

## Main Views

- **Semantic Subspace Map** — renders discourse-role subspaces as hex grids; papers are countries, overlaps are boundary zones; supports selection, routes, and flights.
- **Chat with LLM** — natural-language control: retrieval, subspace construction, summaries, case switching.
- **Semantic Source Gallery** — paper thumbnails per case; selecting papers dynamically filters the map (hexes, scatter points, borders, and conflict regions follow the selection).
- **Stepwise Analysis View** — saves flights/HSUs as analysis cards with structured summaries.

## Gallery Data Sources

- **Backend manifest (preferred)** — if a case has `data/<caseId>/gallery.json` (generated by the backend pipeline), thumbnails and paper↔country mappings load automatically via `GET /api/gallery`. New cases need no frontend changes.
- **Bundled assets (legacy)** — `src/assets/pictures/<folder>/` with hardcoded mappings in `LeftPane.vue` (used by case1/case2).
